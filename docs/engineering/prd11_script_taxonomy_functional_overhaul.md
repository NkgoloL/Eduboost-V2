# PRD-11.2R — Script Taxonomy and Functional Overhaul

PRD-11.2R implements the script-side counterpart to PRD-11.1R. It classifies scripts by domain and function, makes script mutability explicit, and blocks PRD-11.3R until script taxonomy evidence is captured.

The corrective purpose is to prevent release claims from being generated by scripts that merely write or validate governance records. Runtime, product and advisory claims must be backed by scripts that execute real checks or consume real command outputs.

Release boundaries remain locked: production release, deployment, release tags, public beta, billing launch and live payment processing are not authorised by this slice.
