# KG-5 Assessment Generation Contract

Assessment drafts must be exit-check previews grounded in the corresponding KG-5
lesson draft and KG-4 gap evidence. Each item must include an expected answer
contract and a simple rubric suitable for human review.

Assessment drafts are not authoritative diagnostic or grading instruments in
KG-5.
