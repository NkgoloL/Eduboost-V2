# KG-5 Grounded Generation Policy

KG-5 may generate only reproducible preview artifacts from committed KG evidence.
It must not call an LLM provider or use live learner data. Every generated lesson
or assessment draft must reference KG-4 intervention evidence and KG-2 target
provenance.

The generated pack is not learner-facing until a later slice explicitly records
human review, safety review, educator review, and runtime authority.
