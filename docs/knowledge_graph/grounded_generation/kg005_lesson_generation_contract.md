# KG-5 Lesson Generation Contract

Lesson drafts must be derived from KG-4 intervention recommendations and remain
preview-only. Each lesson draft must record the KG-4 intervention key, gap key,
target key, priority bucket, rationale context, instructional strategy, and
review requirement.

The contract forbids live learner identifiers, runtime delivery, and LLM-provider
execution in KG-5.
