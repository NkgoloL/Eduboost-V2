# KG-3 Learner Graph Shadow Runtime Boundary

KG-3 creates a read-model artifact only.

The following remain unauthorised:

- runtime KG implementation;
- runtime KG authority switch;
- database schema migration;
- learner graph persistence;
- learner-facing model changes;
- production release;
- deployment;
- public beta activation.
