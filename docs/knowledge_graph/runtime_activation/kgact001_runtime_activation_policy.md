# KG-ACT-001 Runtime Activation Policy

Runtime KG authority activation may be recorded only when all KG-7 readiness
checks are valid and final activation evidence has been reviewed. This gate
controls the KG authority state only. It does not authorise a production
release, public beta launch, billing launch, release tag, database migration,
or LLM provider call.
