# KG-ACT-001 Runtime Activation Schema

Required evidence fields:

- `runtime_kg_implementation_claimed`
- `runtime_kg_authority_switch_authorised`
- `authority_switch_executed`
- `runtime_activation_go_no_go_approved`
- `activation_feature_flag_contract_recorded`
- `rollback_validation_recorded`
- `learner_safety_validation_recorded`
- `popia_runtime_boundary_confirmed`
- `production_release_authorised`
- `deployment_authorised`
- `public_beta_authorised`

## Final review metadata

Each final KG-ACT-001 evidence document must include:

- `Reviewer` — real named reviewer, not a placeholder
- `Reviewed at` — ISO date or UTC timestamp
- `Reviewer named: true`
- `Reviewed at recorded: true`
