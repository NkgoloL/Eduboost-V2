# Phase 18 Controlled Beta Consent Pack Checklist

This controlled beta consent checklist is part of launch governance and does not authorise production release, deployment, public beta, controlled beta launch activation, live learner traffic, or learner data migration.

## Required Checks

- Guardian consent language reviewed.
- Learner data collection scope documented.
- Data export and erasure routes verified in seeded E2E evidence.
- Support contact provided to guardian.
- Withdrawal route documented.
- POPIA-sensitive data minimisation reviewed.

## Activation Boundary

Consent-readiness documentation is necessary but not sufficient for launch activation. A later activation gate must explicitly authorize the beta cohort and live learner traffic.
