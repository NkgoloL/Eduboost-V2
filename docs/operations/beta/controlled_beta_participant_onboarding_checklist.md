# Controlled Beta Participant Onboarding Checklist

This checklist does not authorise controlled beta launch or live learner traffic.

- Controlled beta launch authorised: false
- Live learner traffic authorised: false

## Guardian / Learner Prerequisites

- Guardian identity/contact captured in controlled beta cohort manifest.
- Guardian consent reference linked to learner alias/internal ID.
- Learner grade confirmed within controlled beta scope.
- Support contact and escalation route shared with guardian.
- Data export and erasure routes explained.
- Retention and withdrawal process acknowledged.

## Internal Prerequisites

- Learner aliases avoid unnecessary personal data in operational evidence.
- Cohort size remains within the controlled beta cap.
- No learner is activated without consent.
- No learner data migration is performed before a separate migration gate.
