# RR-007 Accessibility Audit Plan

Accessibility audit planned: true

## Scope

Accessibility coverage must include:

- learner diagnostic journey;
- AI lesson journey;
- study plan page;
- parent progress view;
- consent/data-rights flows;
- keyboard navigation;
- visible focus states;
- labels/roles for core controls;
- colour contrast and responsive layout checks.

## Evidence expectation

Future audit evidence should cite Lighthouse, axe, Playwright accessibility checks, or a documented manual assistive-technology review.
