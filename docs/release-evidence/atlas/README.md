# Atlas Evidence Namespace

This folder contains the active sprint evidence packages for the `atlas` codename.

## Convention

- Evidence indexes: `docs/release-evidence/atlas/phase-<NN>/phase_<NN>_evidence_index.md`
- Audit reports: `docs/release-evidence/atlas/phase-<NN>/phase_<NN>_audit_report.md`
- Supporting logs, manifests, and extracts should stay inside the same phase subfolder.

Move finished sprint evidence here before closure, and archive it only after the sprint is merged and documented.
