# Reports Directory

This directory contains **historical reports** and review artifacts. These files may contain stale findings, pre-closure roadmap status, or old implementation-order recommendations.

## Current authority rule

Do not treat files in this directory as current roadmap authority unless a newer production-readiness record explicitly promotes one.

Current source-of-truth documents are:

- `docs/current_state.md`
- `docs/roadmap/production_readiness/production_readiness_register.json`
- `docs/roadmap/production_readiness/current_state_documentation_truth_map.json`
- `docs/roadmap/reconciliation/final_roadmap_reconciliation_closure_record.json`
- `docs/roadmap/knowledge_graph/kg_roadmap_closure_record.json`

## PRD-0.2 quarantine rule

PRD-0.2 marks historical reports as retained evidence, not active implementation instructions. Historical reports must include a supersession note before being cited in future planning.

The stale-source quarantine register is:

- `docs/reports/stale_source_quarantine_register.json`
