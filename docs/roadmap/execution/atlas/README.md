# Atlas Sprint Namespace

This folder contains the current roadmap sprint artifacts for the `atlas` codename.

## Convention

- Execution plans: `docs/roadmap/execution/atlas/phase_<NN>_execution_plan.md`
- Implementation reports: `docs/roadmap/execution/atlas/phase_<NN>_implementation_report.md`
- Evidence indexes: `docs/release-evidence/atlas/phase-<NN>/phase_<NN>_evidence_index.md`
- Audit reports: `docs/release-evidence/atlas/phase-<NN>/phase_<NN>_audit_report.md`

Keep any new sprint-specific roadmap artifacts inside this namespace until the sprint is closed and archived.
