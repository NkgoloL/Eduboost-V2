# KG-8 — Post-Switch Optimisation and Scale Review

KG-8 reviews the controlled runtime KG authority activation recorded by KG-ACT-001. It creates a post-switch optimisation and scale-review evidence artifact for the Grade 4 Mathematics KG stream.

## Scope

In scope:

- post-switch optimisation candidates;
- scale review checks;
- monitoring and observability requirements;
- rollback observability checks;
- POPIA post-switch boundary confirmation;
- final KG roadmap completion through KG-8.

Out of scope:

- production deployment;
- release tagging;
- public beta launch;
- live learner traffic;
- billing launch or live payment processing;
- database schema migration;
- learner-facing model change;
- execution of optimisation work or scale load tests.

## Dependency

KG-8 requires valid KG-ACT-001 evidence with the controlled runtime KG authority switch authorised and executed. KG-8 must not run directly after KG-7 readiness-only evidence.

## Evidence rule

The generated post-switch review artifact is repository-local evidence. Final evidence capture also requires reviewed non-template records for go/no-go, optimisation backlog, scale review, monitoring review, rollback review, POPIA boundary, and post-switch boundary.
