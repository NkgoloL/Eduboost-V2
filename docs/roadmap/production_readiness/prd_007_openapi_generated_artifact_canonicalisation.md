# PRD-0.7 — OpenAPI and Generated Artifact Canonicalisation

**Stream:** PRD Production Readiness  
**Status:** Authority pending evidence capture  
**Depends on:** PRD-0.6 Workflow Command Hygiene and CI Inventory  
**Next authorised item after evidence:** PRD-0.8 Branch/Release Naming Reconciliation

## Objective

Canonicalise OpenAPI and generated artifact source-of-truth handling after the workflow command hygiene baseline. The repository currently contains multiple OpenAPI surfaces, including the canonical `docs/openapi.json` and root-level mirrors. PRD-0.7 keeps `docs/openapi.json` as the source of truth and treats root-level `openapi.json` and `openapi.yaml` as generated mirrors.

## In scope

- Record a generated-artifact canonicalisation authority record.
- Keep `docs/openapi.json` as the canonical committed OpenAPI contract.
- Refresh root `openapi.json` from `docs/openapi.json`.
- Refresh root `openapi.yaml` from `docs/openapi.json`.
- Record generated artifact inventory and checksums.
- Record OpenAPI summary counts and mirror equality checks.
- Preserve PRD-0 production-readiness boundaries.

## Out of scope

- No production release, deployment, release tag, public beta, live learner traffic, billing launch, or live payment processing authority.
- No branch/release naming reconciliation. That remains PRD-0.8.
- No broad API contract redesign.
- No route implementation or product behavior change.
- No deletion of historical OpenAPI snapshots unless separately authorised.

## Canonical rule

| Surface | Status | Rule |
| --- | --- | --- |
| `docs/openapi.json` | Canonical | Generated by `scripts/generate_openapi.py`; this remains the source of truth. |
| `openapi.json` | Generated mirror | Must match `docs/openapi.json` byte-for-byte after canonicalisation. |
| `openapi.yaml` | Generated mirror | Must represent the same schema as `docs/openapi.json`. |
| `docs/openapi_pr003.json`, `docs/openapi_pr004.json` | Historical snapshots | Retained as non-canonical historical artifacts. |
| `docs/generated/*` | Generated documentation artifacts | Inventoried, not redesigned in this slice. |
