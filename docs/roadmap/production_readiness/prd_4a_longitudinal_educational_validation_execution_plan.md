# PRD-4A Longitudinal Educational Validation — Implementation Execution Plan

## Purpose

Provide the concrete repository, governance, research, evidence and operational work needed to execute all 222 tasks.

## Execution constraints

- Do not mark empirical work complete without real data and reproducible analyses.
- Do not mark independent review complete through self-review.
- Do not collect child data before lawful authority, consent/assent and approved data controls.
- Do not let technical model performance override fairness, safety or curriculum failures.
- Do not enable unsupported model uses merely because the runtime implementation exists.

## Recommended bundle sequencing

1. Bundle A — WS01 and WS15 foundations: claims, uses, limitations and enforcement.
2. Bundle B — WS02: CAPS, graph and validation item-bank authority.
3. Bundle C — WS03: immutable traceability and registries.
4. Bundle D — WS04, WS05 and WS08: calibration, classification and state reasonableness.
5. Bundle E — WS06 and WS07: retention and transfer.
6. Bundle F — WS09 and WS11: fairness, context and adverse consequences.
7. Bundle G — WS10: controlled educational impact.
8. Bundle H — WS12: replication.
9. Bundle I — WS13: production drift and revalidation.
10. Bundle J — WS14: independent review and final authorisation.

## Status transition

`not_started → in_progress → candidate_complete → evidence_recorded → independent_review → closed`

`blocked` may be entered from any non-closed state. `waived` requires an approved waiver with expiry and restrictions.
