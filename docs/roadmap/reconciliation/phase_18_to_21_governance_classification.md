# Phase 18–21 Governance Classification

**Status:** initial classification / pending evidence capture

## Decision

The runtime-readiness records numbered Phase 18 through Phase 21 are classified as **auxiliary beta-operations governance records**, not canonical roadmap phases.

They remain useful and valid as evidence controls, but they must not be used to automatically extend the canonical roadmap numbering or introduce additional work without reconciliation.

## Classification

| Record | Classification | Canonical relationship |
|---|---|---|
| Phase 18 — Controlled Beta Launch Governance | Auxiliary beta-operations governance | Supports roadmap Phase 14 / Phase 15 operational and governance readiness. |
| Phase 19 — Controlled Beta Activation Preflight | Auxiliary beta-operations governance | Supports roadmap Phase 16 beta-period preparation. |
| Phase 20 — Controlled Beta Launch Activation | Auxiliary beta-operations governance | Supports bounded controlled-beta activation only. |
| Phase 21 — Controlled Beta Launch Monitoring | Auxiliary beta-operations governance | Supports early beta monitoring only; does not prove full beta outcome. |

## Non-authorisations

This classification does not authorise:

- production release;
- public beta;
- production deployment;
- release tagging;
- runtime KG implementation;
- expansion beyond the approved cohort;
- automatic Phase 22+ creation.

## Required rule going forward

Any future work must be selected from `docs/roadmap/reconciliation/outstanding_work_register.md` and cite one or more `RR-###` IDs.
